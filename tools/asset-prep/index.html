Asset Prep

drop PNG / JPG / GIF / WebP / PAM images · drop an .anim or .layers (with its images) to edit it again · everything stays in your browser

    Drop an image to start.

    Sprite sheet → set the cell size, click cells to build clips, download .pam + .anim.
    Background / tileset → download the .pam.

    Sheet

    Click a cell to append it as a frame to the selected clip. Cells are numbered left-to-right, top-to-bottom — the same order the engine uses.

    Clips

    #celltickshitbox x · y · w · h (rel. to origin, facing right)

    Preview

    Red box = hitbox, cross = origin (where the character's feet sit in the world). Pick a frame in the table to edit its hitbox.

    Image

    Export

    In your game: ge_sprite_load(&spr, "hero.pam", "hero.anim") for sheets, ge_image_load_pam(&img, "forest.pam") for plain images.

    Backdrop — parallax layers, back to front

    Drop images while this page is open to add them as layers. factor is how fast a layer scrolls with the camera: 0 = fixed sky, 1 = moves with the level, above 1 = foreground passing in front. Tick front for layers drawn over the characters.

    #imagefactorfactor_ydriftyalphafrontadditiveoptional

    Preview (400×240, drawn the way the engine draws it)

    Export

    Unzip next to your game, then: ge_world_load_layers(&world, "backdrop.layers", &line) — or try it in the demo: ./build/demo --layers backdrop.layers
