Asset Prep

drop PNG / JPG / GIF / WebP sheets and backgrounds · drop an .anim to load clips · everything stays in your browser

    Drop an image to start.

    Sprite sheet → set the cell size, click cells to build clips, download .pam + .anim.
    Background / tileset → download the .pam.

    Sheet

    Click a cell to append it as a frame to the selected clip. Cells are numbered left-to-right, top-to-bottom — the same order the engine uses.

    Clips

    #celltickshitbox x · y · w · h (rel. to origin, facing right)

    Preview

    Red box = hitbox, cross = origin (where the character's feet sit in the world). Pick a frame in the table to edit its hitbox.

    Export

    In your game: ge_sprite_load(&spr, "hero.pam", "hero.anim") for sheets, ge_image_load_pam(&img, "forest.pam") for plain images.
